# 因子台帳

ウマ娘プリティーダービーのデータ（因子・所持ウマ娘・サポートカード・スキル・対人イベント記録）
を登録・検索できる個人用ツール。もともとは因子台帳単体のツールだったが、現在は5ページ構成の
アプリになっている。

データはこのリポジトリの `data/*.json` を GitHub Contents API 経由でDB代わりに読み書きする。
サーバー側の処理は一切なく、静的ファイルのみで完結する（GitHub Pages）。

## ページ構成

| ページ | ファイル | 内容 |
| --- | --- | --- |
| 因子台帳 | `index.html` / `script.js` | 因子（青/赤/白）の継承画面を登録・検索 |
| ウマ娘図鑑 | `uma.html` / `uma.js` | 所持ウマ娘の適性・成長率・所持スキルを登録・検索 |
| サポカ図鑑 | `support.html` / `support.js` | 所持サポートカードの効果・所持スキルを登録・検索 |
| スキルブック | `skill.html` / `skill.js` | スキルの種別・効果・所持ウマ娘/サポカを一覧管理 |
| 対人イベント記録 | `pvp.html` / `pvp.js` | チャンピオンズミーティング・リーグオブヒーローズの成績記録 |

各ページの右上「GitHub連携」ボタンから、この1つのリポジトリに対して同じ接続設定
（所有者・リポジトリ名・ブランチ・PAT）を使い回す。

## アプリとして追加する（PWA）

PWA対応しているので、ホーム画面・デスクトップにアイコンを追加してアプリのように起動できる。

- **スマホ（Chrome/Safari）**: 公開URLを開き、ブラウザメニューの「ホーム画面に追加」または「アプリをインストール」を選択
- **PC（Chrome/Edge）**: アドレスバー右側のインストールアイコンから「インストール」

アイコンから起動すると、ブラウザのアドレスバーなしの独立したウィンドウで開く。

## データの読み取り方法

画像からの自動読み取りはAnthropic APIの課金が必要になるため採用していない。
代わりに以下の手順で、Claudeアプリ（chat）を使って手動で読み取る。

1. 対象のスクリーンショットを撮る（因子継承画面・ウマ娘/サポカのステータス画面など）
2. 各ページの「Claude用プロンプトをコピー」ボタンを押す
3. Claudeアプリ（claude.ai等）を開き、コピーしたプロンプトとスクリーンショットを一緒に送る
4. Claudeが返すJSONをコピーし、アプリの「Claudeの出力を貼り付け」欄に貼り付けて「この内容をフォームに反映」を押す
5. 内容を確認して保存する

もちろん、この手順を使わず手入力で直接フォームに記入してもよい。

## セットアップ

### 1. リポジトリを公開する

このリポジトリがPublicであることを確認する（GitHub Pagesを無料プランで使うには
公開リポジトリである必要がある）。Settings → 一番下のDanger Zoneで確認・変更できる。

### 2. GitHub Pagesを有効化

1. リポジトリの Settings → Pages を開く
2. 「Build and deployment」の Source を `Deploy from a branch` にする
3. Branch を `main`（このリポジトリのデフォルトブランチ）、フォルダを `/ (root)` にして Save
4. 数分待つと `https://<ユーザー名>.github.io/UmaMusumeDB/` でアプリが公開される

### 3. GitHub個人アクセストークン(PAT)を発行（保存・削除する端末のみ）

**閲覧するだけの端末ではこの手順は不要。** リポジトリが公開なので、
読み込みはPATなしでも動作する（GitHubの未認証APIで取得するため
1時間60リクエストまでの制限はあるが、個人の閲覧用途なら十分）。

各データの登録・削除を行う端末では、アプリ画面からこのリポジトリの
`data/*.json`（および画像・動画）を書き込むためにPATが必要になる。

- GitHubの Settings → Developer settings → Fine-grained personal access token で発行
- 対象リポジトリ: このリポジトリのみに限定
- 権限: **Contents: Read and write** のみ付与（他の権限は不要）
- 有効期限はできるだけ短く設定し、期限切れ時は再発行する

このトークンはブラウザの `localStorage` に平文で保存される（個人利用前提の
簡易実装）。共有端末では使用しない、ブラウザのプロファイルを共有しない、など
取り扱いに注意すること。**PATはその端末のブラウザにしか保存されない**ため、
別端末で開いたときは都度この手順で発行・入力し直す必要がある（閲覧だけなら
手順4でPAT欄を空欄のまま進めればよい）。

### 4. アプリを開いて接続

公開したURLを開き、右上の「GitHub連携」ボタンを押すと設定画面が開くので、
以下を入力して「保存して読み込む」を押す。

- リポジトリ所有者（例: `izayoisinya`）
- リポジトリ名（例: `UmaMusumeDB`）
- ブランチ（空欄でデフォルトブランチ）
- PAT（**閲覧のみなら空欄でOK**。保存・削除する場合のみ手順3で発行したPATを入力）

この設定は5ページ共通で使い回される。以降、各ページでClaudeの出力を貼り付け→読み取り→
保存/削除ができる（PATがある端末のみ）。他端末からの更新を取り込みたい場合は
「更新」ボタンで再取得する。

## データの同期について

- 読み込みはページを開いた時と「更新」ボタン押下時のみ（ポーリングはしない）
- 検索・フィルタはメモリ上のデータに対してのみ行う
- 保存・削除のたびに対応する `data/*.json` へのコミットが1つ積まれる
- 書き込み直前に最新の `sha` を取得し直すが、ほぼ同時に他端末が書き込んだ
  場合は409エラーとなる。その場合は画面の案内に従い「更新」ボタンで
  最新を取得してから再度保存・削除する
